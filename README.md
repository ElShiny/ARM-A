# ARM-A

Arm-A is an ongoing project that seeks to create an affordable prosthetic controller. 

### Current status

The first controller was made out of a glove, rotary potentiometers and 3D printed parts. While that works, it is also not very accurate, as the glove is not firmly attached to the hand.

### Future work

I'm looking into HD-EMG signal acquisition from forearm muscles, from which I will try to extract information about finger flexion. I have already set my eyes on INTAN technologies chip RHD2164.
